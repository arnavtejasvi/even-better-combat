# Even Better Combat

Kill streak and death counter with a persistent HUD overlay and chat milestone announcements. Stats are saved per server across sessions.

**Latest release:** v1.0.0 · [Modrinth](https://modrinth.com/mod/even-better-combat)

---

## Features

- Tracks current kill streak and total deaths
- Persistent HUD overlay shows live streak count
- Chat announcements fire at streak milestones
- Stats saved per server/world — resets only on death
- Fully client-side — no server mod needed
